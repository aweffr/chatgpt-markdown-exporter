# DIL 适配评审处理

本次只处理会丢失内容、阻断合法回答或破坏选择流程的问题。

## 逐项结论

| 编号 | 结论 | 依据与处理 |
| --- | --- | --- |
| M1 | 采纳 | 浏览器复现生成结束仍导出半截回答。生成中不预读；生成状态变化使缓存和旧请求失效，消息 ID 相同也重新读取。选择模式在生成开始时退出。 |
| M2 | 保留现状 | 确实存在，但属于已确认的“无法完整解析则不进入选择、不下载”契约。按消息隔离失败会改变默认全选、错误模型和交互，不在本次修复中引入。 |
| M3 | 采纳 | JSX 表达式属性使 XML 解析失败已复现。raw parts 只宽松读取图形文字标签；真正转换 fallback SVG 时仍严格解析，不执行 JSX。 |
| L1 | 采纳 | 空标签签名误删无文字 SVG 代码已复现。不记录空签名；无文字 SVG fence 原样保留，不删除或伪造图形内容。 |
| L2 | 采纳 | 转义反引号和跨段落配对导致链接、引用漏转换已复现。代码分段尊重开头的反斜杠转义和段落边界，保留合法多行代码 span。 |
| L3 | 采纳 | 浏览器复现重建输入框后出现两个工具栏，取消后仍残留一个。选择加载防重入，重挂入口保持禁用，异步结束不再直接访问已移除按钮。 |
| L4 | 不采纳 | `sandbox:` 链接离开 ChatGPT 无法使用，但原始资源链接保留是现有契约。改成附件标签不会恢复下载能力，反而丢失原始路径；不改写。 |
| L5 | 暂不调整 | 未在五份真实样例中出现模态层导致的隐藏误判，也未测得性能瓶颈。此次不扩大到可见性策略和轮询性能改造。 |

来源标题、URL 特殊字符和多附件引用范围的额外校验，没有本次样例中的实际故障，不新增防御逻辑。图表表头保留 API 的 xKey，不推测中文名称。

## 输出契约说明

DIL 的规范正文和引用不依赖 DOM 挂载。仅来自 DOM 的引用回复、思考摘要是挂载时的补充；普通 Markdown 的 DOM 增强也不承诺全文与挂载状态无关。已修正文档和不变量测试名称。
